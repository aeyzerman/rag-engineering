# Apache Parquet: колоночный формат

Apache Parquet - бинарный колоночно-ориентированный формат хранения данных. Разработан для эффективного хранения и аналитической обработки больших данных.

Ключевое свойство Parquet: данные каждой колонки хранятся непрерывно на диске. При аналитических запросах читаются только нужные колонки, а не вся строка. Это ускоряет операции AVG, SUM, GROUP BY в десятки раз по сравнению с CSV.

Parquet поддерживает сжатие: snappy (быстрое), gzip (компактное), zstd. Формат хранит метаданные схемы и min/max статистики для каждого row-group. Это позволяет делать predicate pushdown - пропускать блоки данных без чтения.

Parquet интегрируется со Spark, Hive, Presto, BigQuery, Athena, Delta Lake. Используется для Data Lake, DWH и аналитических пайплайнов. Типичная экономия места составляет от 3 до 8 раз по сравнению с CSV.
